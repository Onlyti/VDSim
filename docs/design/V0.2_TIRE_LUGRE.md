# v0.2 — unified brush/LuGre dynamic tire

Status: **implemented** (2026-06-06), opt-in via `TireParams.lugre.enabled`.
Default off preserves the kinematic blend + brake-hold path (`LOW_SPEED_HANDLING.md`).
When enabled, MF96 supplies the steady-state friction envelope `g()` and per-wheel
bristle states replace the low-speed blend.

## Goal

Replace the low-speed blend with a single physically-grounded tire model in which
the brush (bristle) behaviour and the slip-curve behaviour are the *same* model at
different operating points: brush/stiction dominant as Vx -> 0 (true static hold,
no slip singularity), slip curve dominant while sliding. One state, smooth
transition, no blend/switch.

## Why this is the right model

The brush model is the physical origin of the slip curve: tread bristles deflect
elastically in the adhesion zone (force proportional to slip) and saturate at
mu*Fz in the sliding zone; the integral of that over the contact patch is what
gives a Pacejka-shaped steady-state slip curve. So "brush" and "slip" are not two
models to mix — the slip curve is the *steady state* of the brush model. Making
the bristle deflection a dynamic state (LuGre) adds the missing standstill regime.

## Model (LuGre / brush-dynamic)

Per contact (longitudinal shown; do the lateral analogously, or 2D coupled per
Deur 2004), with relative (slip) velocity v_r:

    z_dot = v_r - (sigma0 * |v_r| / g(v_r)) * z
    F     = sigma0 * z + sigma1 * z_dot + sigma2 * v_r

- z   : bristle deflection state [m]
- g(v_r) : steady-state friction curve. Set g(v_r) = mu(Fz)*Fz * (shape) so that in
  steady sliding F -> the existing Pacejka MF96 output. i.e. reuse MF96 as g().
- sigma0 : bristle stiffness [N/m]
- sigma1 : bristle micro-damping [N.s/m] -- MUST be ~critical,
  sigma1 ~ 2*sqrt(sigma0 * m_eff), or the model rings (this is exactly why the
  v0.1 spring-stick prototype oscillated; see LOW_SPEED_HANDLING.md).
- sigma2 : viscous term [N.s/m] (small/optional)

Limits:
- Vx -> 0 (rest): z_dot -> 0, F -> sigma0*z = elastic stick -> static hold on a
  grade, no 0/0 in the slip definition.
- steady sliding: z -> g(v_r)/sigma0, F -> g(v_r) = MF96 slip curve recovered.

## Integration notes

- z is stiff at high slip (eigenvalue -sigma0*|v_r|/g); use the same substep the
  tire relaxation already uses, or an implicit/semi-implicit z update, to stay
  stable at dt = 0.005 (forward Euler on z went marginally unstable at high slip in
  the v0.1 prototype -- clamp z to the breakaway deflection g/sigma0 if needed).
- Longitudinal + lateral: prefer the 2D coupled bristle (Deur 2004) so the friction
  ellipse falls out naturally instead of a separate combined-slip step.
- Keep MF96 as g() so all the existing load-sensitivity / camber / Mz fits carry
  over; LuGre only changes the *transient + low-speed* behaviour.

## Payoff vs current v0.1 approach

- Removes the kinematic blend, the brake-hold damper, and the lambda force fades --
  one model does standstill hold, low-speed, and high-speed.
- True static friction (hold on a slope with zero creep), correct stick-slip.
- Physically consistent force at all speeds (no display/dynamics split).

Pairs naturally with the v0.2 component workshops (tire TIR import + samples) and
the drivetrain module (`V0.2_DRIVETRAIN.md`).
