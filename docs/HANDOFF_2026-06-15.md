### D. 실험 Python API — `class Sim` (`python/vdsim_lab.py`)

**seam 4개**:
```python
sim.state()            # ground truth dict (+ beta, Fz, slip_*)
sim.measurements(id)   # noisy, mount pose lever-arm 변환
sim.set_input(...)     # action 주입 (CmdL4 or keyword)
sim.run_core_dt()      # core 한 스텝 전진 + 로그
```

**추가 기능 (ablation 피드백 반영)**:
- `state()['beta']`: vehicle sideslip β = atan2(vy, vx)
- `log_extra(d)`: per-step 컨트롤러 내부변수 → to_csv() extra cols
- `reset(v0, x0, ...)`: plant 재사용 (같은 Sim, 다른 controller)
- `register_metric(name, fn)`: 도메인 custom metric → metrics([...])
- `plot_comparison(runs_dict)`: A/B/C overlay figure (ablation)
- `ref_point`: state() 기준점 변환 — `"rear_axle"` / `"front_axle"` / `[rx,ry]`
  - 위치: `p_ref = p_cg + R_yaw·[rx,ry]`
  - 속도(body): `vx -= r·ry`, `vy += r·rx`
  - 가속도(body): `ax -= α·ry + r²·rx`, `ay += α·rx - r²·ry`

**기본 기준점**: **CG** (position/velocity/accel 모두). 뒷축 필요시 `ref_point="rear_axle"`.
